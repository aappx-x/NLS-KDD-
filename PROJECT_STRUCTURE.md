# Project Structure

```
nids-project/
├── data/
│   ├── raw/                    # original NSL-KDD files (KDDTrain+.txt, KDDTest+.txt)
│   └── processed/               # cleaned CSVs + numpy arrays after preprocessing
├── notebooks/
│   └── figures/                 # EDA and feature-importance plots (generated by src/eda.py, src/feature_importance.py)
├── src/
│   ├── columns.py                # column names + attack-category mapping (shared constants)
│   ├── load_data.py              # raw text -> labeled, named CSVs
│   ├── eda.py                    # exploratory analysis + figures
│   ├── preprocess.py             # leakage-safe encoding/scaling pipeline
│   ├── train.py                  # Logistic Regression baseline + Random Forest primary model
│   ├── tune.py                   # RandomizedSearchCV hyperparameter tuning
│   └── feature_importance.py     # Gini + permutation importance
├── models/                        # saved fitted objects (.joblib): preprocessor, both models, importances
├── app/
│   ├── app.py                     # Streamlit demo
│   ├── sample_presets.json        # 5 real example rows (one per attack category)
│   └── categorical_options.json   # dropdown values for protocol_type/service/flag
├── docs/
│   ├── interview_guide_part1.md   # Level 1-3 explanations: dataset, preprocessing, ML, evaluation
│   ├── interview_guide_part2.md   # cybersecurity concepts + deployment walkthrough
│   ├── interview_qa_easy.md
│   ├── interview_qa_medium.md
│   ├── interview_qa_hard.md
│   ├── study_roadmap.md
│   └── resume_output.md
├── requirements.txt
├── README.md
└── PROJECT_STRUCTURE.md           # this file
```

## Run order
1. `python src/load_data.py`
2. `python src/eda.py` (optional, produces figures)
3. `python src/preprocess.py`
4. `python src/train.py`
5. `python src/tune.py` (slower — RandomizedSearchCV with cross-validation)
6. `python src/feature_importance.py`
7. `streamlit run app/app.py`
